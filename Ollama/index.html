Test Models

After installing a preview build, run the published GPT-OSS and Apertus 1.0 test models, or create Gemma 4 and Apertus 1.5 Omni locally from Hugging Face weights. Apertus 1.1 Mini artifacts are currently under conversation-quality investigation.

Browse all published test models at ollama.com/pd95.

Or download models from Hugging Face and convert them yourself.

ollama run pd95/gptoss-mlx:20b ollama run pd95/apertus-mlx:8b

Apertus tags: use 8b-nvfp4 as the compact default, 8b-mxfp8 for higher quality, and 8b-bf16 as the large reference build.
